# 学习助手 UI 视觉改版 — 设计规格

> 日期：2026-08-14
> 状态：已评审，待实现
> 目标：把学习助手网页改成清新浅色风格（樱花粉紫系），仿 Claude 网页版质感，加入原创二次元插画（白发红眸古风少女吉祥物）。

---

## 1. 背景与目标

当前前端是深色主题（黑底 `#0d0d0d`、暗色边框），组件为 App.vue / FocusTimer.vue / TaskList.vue / AiPlanner.vue。用户希望改成清新浅色风格，视觉上靠近 Claude 网页版的简洁质感，并加入二次元插画元素。

**核心诉求**：
- 浅色、清新、樱花粉紫配色
- 原创二次元插画（横幅 + 吉祥物 + 背景），不下载网图、无版权风险
- 吉祥物为「白发、红眸、一袭红装、古风、高马尾」的少女，简洁扁平可爱风
- 去除所有 emoji

---

## 2. 关键决策

| 决策点 | 选择 |
|--------|------|
| 配色基调 | 浅色清新（暖白底） |
| 配色方向 | 樱花粉紫系 |
| 二次元元素形式 | 原创 SVG 插画（非 emoji、非网图） |
| 吉祥物形象 | 二次元少女：白发、红眸、红装、古风、高马尾 |
| 插画风格 | 简洁扁平可爱风 |
| 插画位置 | 背景 + 顶部横幅 + 吉祥物头像（三处） |
| emoji | 全部去除，换文字 + 插画 |
| 技术 | 纯 CSS + Vue scoped style，无 UI 库、无新依赖 |

---

## 3. 配色（樱花粉紫系）

| 用途 | 色值 |
|------|------|
| 页面背景 | `#FAF7F2` 暖白 |
| 主色（按钮、强调） | `#F5A0B0` 樱花粉 |
| 辅色（渐变、点缀） | `#B8A7E0` 淡紫 |
| 强调（深粉、hover） | `#E8899A` 深粉 |
| 卡片背景 | `#FFFFFF` 白 |
| 卡片边框 | `#F0E6E8` 极淡粉 |
| 正文文字 | `#4A4458` 深灰（不用纯黑） |
| 次要文字 | `#9A92A8` 灰紫 |
| 吉祥物红装 | `#C8474F` 朱红（插画内视觉焦点） |

渐变主方向：标题与关键数字用「樱花粉 → 淡紫」渐变。

---

## 4. 插画设计（原创 SVG）

新增 `web/src/assets/` 目录存放 SVG 资源。

### 4.1 背景（整页）
- 极淡的 SVG：飘落的樱花花瓣（粉色）+ 小星星（淡紫），半透明，铺在页面底层，不干扰文字。
- 实现为 `background-image` 或绝对定位的 SVG 图层，`pointer-events: none`。

### 4.2 顶部横幅
- 横向 SVG 插画：暖白渐变天空 + 樱花，画面中是一个简洁扁平风格的二次元少女（白发高马尾、红眸、红装古风）坐在书桌/樱花树下学习的意象。
- 放在 `<h1>` 标题之上，宽度自适应。

### 4.3 吉祥物头像
- 圆形头像 SVG：少女头像特写 —— 白发高马尾、红色眼睛、红色古风衣领（交领）。
- 常驻于计时器卡片旁（或标题旁），陪伴专注。

**人物特征（三处插画统一）**：白发、红眸、红色交领古装、高马尾、简洁扁平圆润线条。

---

## 5. 各组件改造

### 5.1 App.vue
- 暖白背景 + 樱花背景层。
- 顶部横幅插画 + 渐变标题「沉浸式学习助手」（去掉 🧘）。
- 全局 CSS 变量集中定义配色。

### 5.2 FocusTimer.vue
- 大白圆角卡片 + 柔和阴影。
- 大号渐变数字时钟（樱花粉 → 淡紫）。
- 「暂停 / 继续 / 结束」按钮：粉/紫配色，圆角。
- 旁挂吉祥物头像。
- 去掉「⏸ ▶ 🛑」等 emoji，用纯文字。

### 5.3 TaskList.vue
- 白卡片列表，每项圆角卡片。
- 「专注」按钮樱花粉；完成态淡紫划线。
- 去掉「▶ ✓ ↩ ✕」emoji，换文字或符号。

### 5.4 AiPlanner.vue
- 白卡片 + 柔和输入框。
- 粉色主按钮「智能规划」。
- 去掉「🤖 ✨ ✅」emoji，换文字。

---

## 6. 非目标（本改版不做）

- 不做浅色/深色切换。
- 不引入任何 UI 组件库（Element/Vant 等）。
- 不引入 AI 生成图片或网图（版权风险）。
- 不改动任何后端逻辑、API、数据结构。

---

## 7. 测试策略

- 前端构建通过（`npm run build`）。
- 冒烟验证：启动前后端，确认四个组件渲染正常、文字可读、无 emoji 残留、插画显示正常。
- 视觉验证：截图或目测确认配色、插画、布局符合规格。

---

## 8. 遗留说明

SVG 人物为简洁扁平风格，非精细立绘，这是本设计的明确取舍（见背景）。
